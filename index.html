Commandes

Z/↑ accélérer · S/↓ freiner/reculer
QD/←→ tourner · Espace frein à main
NITRO : un seul bouton → Maj (ou le bouton 🔥 à l'écran) · R replacer · C caméra · Échap pause
Manette USB / PlayStation / Xbox : ✕ démarrer (accélère aussi) · □ accélérateur · △ marche arrière / frein · O = NITRO · R1 drift · croix : gauche / droite pour tourner, haut avancer, bas frein · stick gauche : volant + avant / arrière · stick droit : haut gaz, bas frein, gauche drift, droite nitro · Select replacer · clic stick caméra · Start pause.
Dans les menus : croix ou stick pour se déplacer (modes, voitures, options…), ✕ choisir, Start lancer la course, O retour, L1 / R1 changer d'onglet. Pause et fin de course : croix ou Select pour choisir, ✕ ou Start pour valider.
Si un bouton ne fait pas ce qu'il faut (manette USB générique), configure-la :

Le nitro se recharge quand tu drifts, et d'un coup quand tu roules sur une bouteille bleue posée sur la route. Prends les raccourcis (panneaux orange) pour gagner du temps.
